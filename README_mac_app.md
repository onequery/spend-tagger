# macOS 지출 태깅 앱

`spending_tagger_app.py`는 macOS에서 실행되는 데스크탑 GUI 앱입니다.

## 기능
- 엑셀(`.xls`, `.xlsx`) 여러 개 입력 후 통합
- 은행계좌 출처에서 월별 카드결제 대금(카드사 출금) 자동 `제외` 처리
- 카테고리/세부카테고리 자동 태깅
  - 규칙 기반(기존 라벨 + 메모리)
  - 선택적으로 GPT(OpenAI API) 사용
- 신규/낯선 엑셀 포맷에서 기본 헤더 탐지 실패 시 GPT로 `헤더 행 + 컬럼 매핑` 자동 추론 폴백
- `미분류` 또는 `타행송금/타행이체` 성격 항목은 사용자 수동 분류를 필수 요구
- 확신 낮은 항목 수동 검토
- 결과 출력
  - `태깅결과_통합지출내역.xlsx`
  - `월별_총지출_요약.xlsx`
  - 파이차트(카테고리/세부카테고리/월별/세부카테고리 전체)

## 실행
```bash
conda activate tmp
python spending_tagger_app.py
```

또는 Finder에서 `SpendTagger.app`을 더블클릭해 실행할 수 있습니다.

## GPT 자동 태깅 사용
- 앱에서 `GPT 자동 태깅 사용` 체크
- API Key 입력 (또는 `OPENAI_API_KEY` 환경변수 사용)
- 신뢰도 임계값 이상만 자동 확정, 나머지는 수동 검토
- API Key가 입력되어 있으면 컬럼 인식 실패 시 GPT 포맷 파싱 폴백도 함께 사용됩니다.

## 온톨로지 편집
- 앱의 `카테고리/세부카테고리 온톨로지` 영역에서 `온톨로지 편집` 클릭
- 카테고리/세부카테고리를 추가 또는 삭제 가능
- `기본값 복원`으로 기본 온톨로지로 되돌릴 수 있음
- 온톨로지는 `ontology.json`에 저장되어 다음 실행에도 유지됨
- 불확실 항목 검토 팝업에서도 카테고리/세부카테고리 추가/삭제가 가능하며, 수정 즉시 온톨로지에 반영됨

## 신규 포맷 컬럼 매핑
- 기본 룰(컬럼 별칭)로 `지출날짜/사용처/지출금액` 인식이 안 되면 컬럼 매핑 팝업이 자동으로 뜹니다.
- 팝업에서 `헤더 행` 선택 후 표준 컬럼에 원본 컬럼을 지정하면 즉시 처리됩니다.
- `프로필 저장`을 체크하면 동일 포맷 파일은 다음부터 자동 인식됩니다.
- 매핑 프로필은 `column_mapping_profiles.json`에 저장됩니다.
